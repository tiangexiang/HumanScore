MuJoCo model of the human skeleton (Rajagopal joint set with MeTRAbs keypoint sites), adapted from
https://github.com/robfiras/loco-mujoco (MIT License).

* `humanoid_torque.xml`: the skeleton that is fitted to the keypoints.
* `humanoid_torque_vis.xml`: the same skeleton for rendering (`baseline/main.py`).
* `meshes/`: bone meshes.
